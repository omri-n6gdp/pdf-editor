# Redline · PDF Editor

**▶ Try it online: [https://omri-n6gdp.github.io/pdf-editor/](https://omri-n6gdp.github.io/pdf-editor/)** (works on phones too)

Redline: in-browser PDF editor. Nothing leaves your machine.

## How to use

Double-click **`index.html`** (or drag it into Chrome or Safari). Nothing to install.

## Files

- `index.html`: the whole app (HTML, CSS and JavaScript in one file)
